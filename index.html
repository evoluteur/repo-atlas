GitHub token

GitHub only shows when each star was given to signed-in callers, so the real star history needs a token. A fine-grained token with no permissions is enough; it only reads public data. It stays in this browser tab and is sent to api.github.com only. It also lifts the rate limit from 60 to 5,000 requests an hour.

Share

A card sized for social posts, and a permalink for this atlas.

Groups

Topics are split into words, weighted by how rare they are across the account, and compared repo to repo. Repos that stay similar enough are merged (average linkage, cut at 0.16). The eight biggest groups by stars get a color; the rest fold into loners.

Highlights

One repo per colored group: the one with the most stars, ties going to the most recently pushed. Hover a card to find its group on the map.

Stars over time

Without a token the chart shows stars held today, by the year each repo was born. With a token it reads stargazer dates: every page for small repos, and five evenly spaced pages for big ones, interpolated in between.

Source

Public GitHub REST API, read from your browser. Forks are left out. Code on GitHub.
